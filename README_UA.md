# PsychoOverlay — LSD/Nilk overlay з режимами

Це прозорий Windows overlay поверх екрана з Nilk/LSD-подібними переливаннями. У цій версії ефекти стали не просто статичним кольоровим шаром: додано **режими**, **плавне підсилення через surge**, використання підготовлених текстур `Cosmos`, `Psychedelic`, `Void`, `Noise`, а також окремий **glyph glitch** у стилі поламаного тексту, ієрогліфів, символів і розірваних рядків, як у твоєму референсі.

## Запуск

Готовий exe лежить тут:

```bat
C:\Users\Lolme\OneDrive\Desktop\PsychoOverlay\publish\PsychoOverlay.exe
```

Або можна запускати через файл:

```bat
C:\Users\Lolme\OneDrive\Desktop\PsychoOverlay\run_overlay.bat
```

## Режими

| Хоткей | Режим | Що робить |
|---|---|---|
| `Ctrl + Alt + 1` | **Flow** | Найлегший режим для ігор: м'які переливання, хвилі, chromatic threads. |
| `Ctrl + Alt + 2` | **Texture Trip** | Додає LSD-текстури `Cosmos`, `Psychedelic`, `Void` поверх хвиль. |
| `Ctrl + Alt + 3` | **Glyph Glitch** | Додає поламаний текст, символи, ієрогліфи, scanline-глітчі та зміщення. |
| `Ctrl + Alt + 4` | **Full Trip** | Найсильніший режим: текстури, glyph glitch, datamosh-блоки, sigils, сильніший surge. |
| `Ctrl + Alt + Left/Right` | Перемикання режимів | Швидко перемикає режим назад або вперед. |

## Інтенсивність

| Хоткей | Дія |
|---|---|
| `Ctrl + Alt + Up` | Підсилити ефект вручну. |
| `Ctrl + Alt + Down` | Послабити ефект вручну. |
| `Ctrl + Alt + Space` | Пауза / продовжити анімацію. |
| `Ctrl + Alt + Esc` | Вийти з overlay. |

## Що саме додано

| Елемент | Опис |
|---|---|
| **Surge-підсилення** | Ефект сам трохи “дихає”: хвилі, текстури та глітчі періодично стають сильнішими. |
| **Режими 1–4** | Кожен режим має іншу базову силу та набір ефектів, а не просто зміну прозорості. |
| **Glyph glitch** | Плаваючі рядки з символами, ієрогліфами, цифрами, NILK/VOID/COSMOS, з RGB-зміщенням. |
| **LSD-текстури** | Використовуються підготовлені `Cosmos.png`, `Psychedelic.png`, `Void.png`, `WavyBlotchNoiseDetailed.png`, якщо вони є в `Assets`. |
| **Datamosh/scanlines** | У сильніших режимах з'являються горизонтальні розриви, блоки та “биті” фрагменти. |

## Продуктивність

Overlay і далі рендериться як прозоре click-through вікно через один постійний 32-bit DIB surface. Це значно легше, ніж створювати новий fullscreen bitmap кожен кадр. Якщо в грі все одно відчутно просідає FPS, використовуй `Ctrl + Alt + 1` або зменшуй силу через `Ctrl + Alt + Down`. Якщо хочеш максимально трешовий LSD, став `Ctrl + Alt + 4` і підкручуй `Ctrl + Alt + Up`.

## Важливе обмеження

Це саме **прозорий overlay поверх екрана**, а не shader всередині гри. Тому він не може по-справжньому викривляти framebuffer гри під собою, як Terraria/Nilk shader. Натомість ця версія імітує LSD через прозорі кольорові шари, текстури, глітч-рядки, datamosh та chromatic effects.
