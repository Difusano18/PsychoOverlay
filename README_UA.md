# PsychoOverlay

Повноекранний WebGL-ефект для вибраного монітора. Програма захоплює екран, обробляє кадр і показує результат поверх дисплея.

## Запуск

Запусти `run_overlay.bat`. Натисни кнопку захоплення й вибери **весь монітор** у вікні Windows. `Ctrl+Alt+R` зупиняє захоплення та відкриває вибір джерела повторно.

## Режими й клавіші

| Клавіші | Дія |
|---|---|
| `Ctrl+Alt+1`–`5` | Flow, Texture, Glitch, Full Trip, Chaos |
| `Ctrl+Alt+6` | NILK STAGE I |
| `Ctrl+Alt+7` | NILK STAGE II |
| `Ctrl+Alt+8` | NILK STAGE III |
| `Ctrl+Alt+PageUp/PageDown` | Перемкнути доступну Nilk palette |
| `Ctrl+Alt+Left/Right` | Перемкнути режим |
| `Ctrl+Alt+Up/Down` | Загальна сила |
| `Ctrl+Alt+Space` або `Ctrl+Alt+P` | Пауза / продовження |
| `Ctrl+Alt+R` | Зупинити захоплення / вибрати монітор |
| `Ctrl+Alt+Esc` або `Ctrl+Alt+Q` | Вийти |

## Nilk 6 / 7 / 8

Після повторного розбору історії upstream стало ясно, що референсне відео треба відтворювати через shader з **Wrath of the Gods 1.2+**. Старий shader 1.1.20 від 2024 року мав тільки вертикальні двочастотні хвилі, blur і palette remap. У ньому ще не було broad XY cos-warp, previous-frame datamosh і Perlin feedback, тобто саме тих ознак, які роблять референсний Nilk рідким і «риплявим».

Тому режими 6/7/8 тепер не є трьома різними вигаданими фільтрами. Усі три запускають одну й ту саму актуальну Nilk-формулу 1.2+: broad XY warp, дві високочастотні хвилі, `datamoshIntensity = 0.51`, Perlin noise, попередній **вже відфільтрований** кадр, 12-tap центральний blur, `sin(luminance * 2PI - globalTime * 1.5)`, vignette та оригінальні палітри без `TransFlag` і `Unpleasant`.

Різниця між стадіями лише в реальній `intensity` тієї самої формули:

- **Stage I / 6:** `0.58` — broad warp уже видно, але datamosh ще слабший через `pow(intensity, 2.5)`.
- **Stage II / 7:** `0.80` — сильні рипли, помітне плавлення попереднього кадру.
- **Stage III / 8:** `1.00` — повний Nilk, як на найсильніших моментах референсу.

Додано ще одну важливу частину upstream pipeline: `ManagedScreenFilter.Opacity` в оригінальному Luminance не вмикається миттєво, а росте приблизно на `0.015` за кадр. WebGL тепер повторює цей ramp як `0.9/сек` і застосовує той самий cubic smoothstep `opacity² * (3 - 2*opacity)`. Через це запуск Nilk більше не стрибає одразу в максимальне викривлення.

Feedback ping-pong тепер працює на **всіх трьох** Nilk-стадіях і не скидається при переході 6 → 7 → 8, тому посилення виглядає як одна безперервна деградація кадру, а не три окремі ефекти. Feedback оновлюється лише на новому capture frame, щоб 120/144/165 Гц монітор не проганяв один 60 FPS кадр кілька разів.

Для продуктивності внутрішній pixel budget розподілений по стадіях: Stage I ≈ 1.8M, Stage II ≈ 1.55M, Stage III ≈ 1.35M пікселів, при цьому overlay як і раніше займає весь вибраний монітор.
